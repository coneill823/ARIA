# Skill sources — one git repo per line; # disables a line.
# `aria install-skills` clones/updates each into vendor/ and links its
# skills where A.R.I.A. can load them (first source wins on name
# collisions). Then `aria skills convert` rebuilds the universal pack.
#
# A source marked `engine-only` is linked into skills-library/ instead of
# .claude/skills/: A.R.I.A.'s own agents, chat and autopilot use it, but
# Claude Code sessions in this repo are not handed hundreds of extra skills.
# A source's agents/ folder becomes her agent library either way.
